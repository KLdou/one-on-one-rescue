# Один на один: Симулятор спасения (Модульная версия v2.0)
*(Всеобъемлющая спецификация игры на основе реальной практики кураторов МБООПЖ «Зоошанс», г. Минск)*

Данная папка (`game_modular/`) представляет собой архитектурно разделенную, модульную версию симулятора спасения животных. Вся логика, стили, разметка и данные вынесены в отдельные специализированные файлы для максимального удобства редактирования, балансировки и расширения согласно Master GDD v2.0 (`v2_0.md`).

## 🌟 Ключевые нововведения и механики версии 2.0

1. **Единая экономика в белорусских рублях (BYN):**
   - Никаких долларов и пересчетов. Зарплаты (1650 / 2800 / 4600 BYN), стартовый бюджет (280 / 600 / 1120 BYN), цены клиник, закупки снабжения на 14 дней (65 / 120 BYN), лимит талона «Зоошанса» (1000 BYN) и лимит карты (6500 BYN/год).

2. **Пошаговая «Острая фаза» (Дни 1–3):**
   - Первые 3 дня автоматический таймер отключен — игрок спокойно осваивает интерфейс и переходит между днями вручную по кнопке `«🌙 Завершить день»`. С 4-го дня активируются скорости 1x, 2x, 5x и «⏩ Промотать штиль».

3. **Прогрессивный онбординг («Туман войны» новичка):**
   - Игрок начинает как обычный человек с улицы: вкладки помощи волонтеров и пиара скрыты.
   - Базовые действия:
     - `«🏛 Позвонить на ул. Гурского, 42»` — узнать правду об отлове и усыплении;
     - `«📦 Подбросить коробку»` — ловушка малодушия с поражением;
     - `«🔍 Погуглить: "Нашел животное в Минске"»` — находит памятку «Зоошанса» и открывает все возможности.

4. **Двухсегментная шкала Энергии:**
   - Наглядно показывает доступную энергию (зеленый) и заблокированную на ежедневный быт дома (оранжевый с `🔒`). При переезде на любую передержку бытовой резерв обнуляется (`0⚡/день`), давая мгновенное облегчение.

5. **Механика «Второго дыхания» при выгорании:**
   - При падении Менталки до 0% один раз за партию игрок может написать крик души в чат волонтеров `@zooshans_chat` и восстановить +45% Менталки.

6. **Умная перемотка спокойных дней («⏩ Промотать штиль»):**
   - Автоматически останавливается ровно за 1 день до любого из 12 критических ветеринарных и организационных дедлайнов.

7. **Разбор ошибок и карточка 9:16 (Bridge to Reality):**
   - При поражении выводится блок «Работа над ошибками» с реальным ветеринарным разбором (коровье молоко, окна без сеток, отлов, перекупщики).
   - В финале генерируется карточка формата 9:16 для публикации в Stories / Telegram со статистикой и кодом ЕРИП `4346991`.

## 🛠️ Как редактировать игру без знания кода (через JSON)

Все балансные параметры и тексты вынесены в папку `data/`:

1. **Изменить цены и лимиты** (`data/config.json`):
   - Стоимость процедур (`prices.spayCat`, `prices.pcrProfile`, `prices.traumaSurgery` и др.).
   - Лимит долга по талону «Зоошанс» (1000 BYN) и лимит сбора на карту (6500 BYN).

2. **Добавить или изменить архетип животного** (`data/scenarios.json`):
   - Все 19 сценариев (слепыши, травмы, подозрение на панлейкопению/ФИП, дички, семейство с дач и т.д.).
   - Можно менять возраст, число котят, скрытые инфекции (`hiddenState.deadlyVirus`, `hiddenState.chronicCarrier`), тексты описаний.

3. **Настроить окрасы и привлекательность** (`data/coats.json`):
   - Коэффициенты звонков от 0.22x («коровка») до 2.0x (шотландцы/британцы).

4. **Добавить новые диалоги ручек и аферистов** (`data/calls.json`):
   - Звонки от мошенников («дальнобойщик с курьером», перекупщицы).
   - Разговоры с потенциальными хозяевами (деревня, съемная квартира, дети-мучители, компромиссные семьи, сетки «Антикошка»).

## 🚀 Запуск игры

### Вариант 1: Локальный веб-сервер (Рекомендуется для редактирования JSON)
При запуске через сервер игра подтягивает самые свежие изменения из файлов в папке `data/`:
- **Python**:
  ```bash
  python -m http.server 8000
  ```
  Затем откройте в браузере: `http://localhost:8000/game_modular/`

- **Node.js**:
  ```bash
  npx serve game_modular
  ```

### Вариант 2: Запуск без сервера (Двойной клик на `index.html`)
- Игра содержит защитный fallback в `js/data_loader.js`. Если браузер блокирует локальный `fetch()` по протоколу `file://`, игра автоматически использует встроенную базу данных и запускается мгновенно без каких-либо ошибок.
